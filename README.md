# BrainSpeak
Open-vocabulary decoding of EEG signals into a semantic (FastText) vector space,
with a silent speech transfer experiment.

Final-year research project — Informatics Institute of Technology /
University of Westminster.

## Datasets (not included — download separately)
- ZuCo 1.0: https://osf.io/q3zws/
- ZuCo 2.0: https://osf.io/2urht/
- BCI Competition 2020 Track 3: https://osf.io/pq7vb/
- FastText English vectors: https://fasttext.cc

## Setup
conda create -n brainspeak python=3.10
conda activate brainspeak
pip install -r requirements.txt"# BrainSpeakNon-Invasive-Silent-Speech-Translation-using-Semantic-Space-Projection-of-EEG-Signals"
